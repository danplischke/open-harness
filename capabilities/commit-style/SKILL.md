# Commit style

Use [Conventional Commits](https://www.conventionalcommits.org): `type(scope): summary`.

- Keep the summary under 72 characters, imperative mood.
- Reference issues with `#NN`.
- Common types: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`.
